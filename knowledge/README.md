# Knowledge

Store reference materials here -- research findings, competitive analysis, customer feedback, technical notes, or anything that helps you do your work.

This folder is for your personal reference. It's not shared with other PMs.

## Suggested Organization

```
knowledge/
├── research/          -- Market research, competitive analysis
├── customer/          -- Customer feedback, interview notes
├── technical/         -- Technical notes, architecture docs
└── reference/         -- Anything else useful
```
